# Examples

The examples directory will hold capability-focused implementations that share the repository’s common scenario contract.

## Planned Sequence

1. `01-research-to-decision` — source-grounded research and artifact generation
2. `02-durable-work` — interruption, persistence, and resumption
3. `03-tools-and-approval` — bounded tool use with human approval
4. `04-delegated-work` — parallel or specialized work where supported
5. `05-evaluation-and-replay` — regression dataset, traces, and failure analysis

An example is not complete until it includes setup, architecture, tests, evaluation evidence, and known limitations.
